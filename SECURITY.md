# Security Policy

## Supported versions

WorkVCS has not made its first public release. Security fixes currently target
the latest repository revision only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. If
that channel is unavailable, contact the maintainer through a private channel
listed on the GitHub profile for `feng2r200`. Do not disclose the vulnerability
in a public issue, discussion, pull request, or WorkVCS Store.

Include, where safe:

- the affected revision and platform;
- impact and realistic attack preconditions;
- a minimal reproduction or proof of concept;
- whether credentials, Store integrity, path handling, bundle import, or Git
  integration are involved;
- any suggested mitigation.

You should receive an acknowledgement within seven days. A remediation and
disclosure timeline will follow after impact and reproducibility are assessed.

## Sensitive data

WorkVCS records structured project state and provenance. Reports must redact
credentials, private project content, personal data, absolute user paths, and
Store contents that are not necessary to reproduce the issue.
