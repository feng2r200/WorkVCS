# Support

WorkVCS is currently maintained on a best-effort basis.

Use the repository's issue templates for reproducible bugs and focused feature
proposals. Use discussions, when enabled, for usage questions and design
conversation. Before asking for help, read the
[operator quickstart](docs/operator/quickstart-and-recovery.md), the
[error recovery guide](docs/operator/error-recovery-guide.md), and the CLI
help for the affected command.

Please include the revision or version, platform, Rust version, exact command,
expected result, actual result, and a sanitized minimal reproduction. Never
post credentials, proprietary source, or private WorkVCS Store data.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not the public
support process.
